# CJGR Career OS Ω — Career Automation Adapter

**Private ChatGPT plugin:** https://chatgpt.com/plugins/plugins_6ac7ce84e7848191baeba88b3f014f4e

A GitHub adapter to the private career operations environment. This PUBLIC repository stores only generic operating code and integration contracts. It **does not** contain CVs, passports, tax files, personnel contracts, private email, private applications or personal contact details.

## Current structure
- Private CV version master: Google Drive; CV_VERSION_INDEX, FACT_RECONCILIATION, CHANGE_LOG.
- Operational pipeline in that same native Google Sheet: CAREER_OPPORTUNITIES, CAREER_APPLICATIONS, CAREER_AGENTS.
- New private operational folder: `CJGR_CAREER_OS_OMEGA_2026`.
- ChatGPT plugin `cjgr-career-os` v1.0.0: Career Scout, Evidence Auditor, ATS Engineer, Application Manager, Recruiter Relations, Interview Strategist, Analytics and Systems Steward; routed through `CJGR Executive Twin Ω`.
- Existing hourly job watch: source monitoring only; no automatic ATS submission.

## Strict eligibility gates
Job active; employer verified; fully remote work from Mexico explicitly accepted; published **guaranteed BASE salary minimum** at least MXN 50,000 gross per month (with dated FX provenance for other currencies); hard requirements checked against documented evidence. Never claim an ATS acceptance probability or 98–100% fit purely from keywords.

## Boundary
`SOURCE → CHECK → SCORE → DRAFT → REVIEW → APPROVE → SUBMIT → LOG → FOLLOW-UP`.

Recruiter email, applications, profile publication and document sharing require prior explicit approval. **No secrets** in this public repo. Google Drive connectors are invoked when the user or configured tasks execute; storing a link is not a live always-on sync.

Portable private-source package and unit-tested CLI are supplied to the owner separately.
