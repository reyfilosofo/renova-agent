# Example-only data

No real user CVs or real job applications are stored here. Use private Google Drive as data store. If testing the local CLI, its example *.json explicitly carries test-only synthetic employers; the code never applies for a job automatically.

The canonical rules and source-code archive are bundled in private `CJGR_CAREER_OS_OMEGA_PLUGIN_1.0.0.zip`, distributed only to the user.
