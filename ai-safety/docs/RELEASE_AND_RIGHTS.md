# Release scope, rights and safety gates

Release: public research-candidate branch created 2026-10-15.
- **Included**: handwritten/reviewed technical prototype, synthetic examples, unit tests, non-frozen research protocol, threat model.
- **Excluded**: book manuscripts, proprietary philosophy corpus, original PDFs/DOCX, contact lists, contracts, API tokens, personal records, full confidential SERESARTE files, deploy credentials, unpublished results.
- **License**: No permission to reproduce, modify, distribute, or commercially exploit this code is granted by virtue of repository visibility. The repository currently has no published license; a code license and contributor policy require a rights-holder decision.
- **No deployment approval**: code is an offline demonstration, not a tool proxy, validated agent guard, safety certification or alignment technique.
- **No empirical data or external relationship**: unit/fixture checks do not prove causal mitigation; no research participant, reviewer, university, laboratory or institution is claimed to have approved the protocol.
- **Before public scientific claims**: complete threat-model review, code review, human independent evaluation, registered confirmatory design, ethics/privacy screening where applicable, and disclosure of negative findings.
- **Before collaboration**: select an explicit license, author/affiliation and contributor credit policies, reporting channel for security vulnerabilities, and responsible disclosure criteria.
- **Review protocol**: work by pull request; do not merge into main until review/rights checks are complete.
