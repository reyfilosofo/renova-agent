# ℛenova × SERESARTE AI Safety Lab — research candidate 0.1

**Status: offline proof of concept only. NOT deployed, NOT independently validated, NOT AGI alignment or containment.**

Research question: can the addition of CENTRO action triage and LUCEM epistemic labeling to conventional, independently enforced tool controls reduce unauthorized *executed* actions while maintaining legitimate task completion?

This public branch includes **only selected synthetic tests, demonstration code, and prospective methodology**. It does not include private ℛenova books, proprietary manuscripts, customer information, account credentials, or production connectors.

## Repository map
- renova_guard/gate.py: standalone deterministic ALLOW / REVIEW / DENY rule demonstration, *not* a security boundary.
- renova_guard/cli.py: local synthetic fixture runner.
- tests/test_gate.py and fixtures/demo.json: unit checks and fictional fixtures.
- docs/RAS_EXP_01_DRAFT.md: prospective controlled study; unfrozen and unexecuted.
- docs/THREAT_MODEL.md: assumptions, failure modes, and controls required before any deployment.
- docs/RELEASE_AND_RIGHTS.md: publication scope, rights, security and review status.

## Reproduce locally

Use Python 3.10+ without third-party dependencies. From inside the ai-safety directory:

    python -m unittest discover -s tests -v
    python -m renova_guard.cli fixtures/demo.json

Passing synthetic fixtures is **not evidence** that any deployed agent is safer. 'ALLOW' is just a test label; it does not execute tools. Inputs like authorized/risk/reversible are currently caller-supplied and cannot be trusted if generated by an AI model.
