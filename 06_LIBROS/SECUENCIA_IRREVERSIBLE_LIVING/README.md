## Provenance

Every reserved copy receives:

- cryptographically random 40-hex seed;
- SHA-256 edition hash;
- edition code `RNV-SIR-2026-XXXXXXXXXXXX`;
- timestamp;
- buyer-selected language/tier;
- optional wallet provenance.

The artwork is deterministically generated from the seed, so provenance is reproducible while page states remain highly variable.

## AI / MACHINE WARS

AI is used as a controlled mutation engine, not as a claim of autonomous authorship. The buyer's choices become part of the edition input. The machine generates a compact poetic kernel that is materially reinterpreted across the 111-page architecture.

The system explicitly avoids claiming that the AI replaces the author or that an NFT proves artistic value.

## Web3 policy

**No NFT is minted by default.** Wallet connection is optional. The downloadable metadata is preparation for a possible later mint and records `minted: false` until a real on-chain action exists. Purchase does not transfer copyright and the work makes no investment or appreciation promise.
