# Tests

## Test 1 - Enter artwork, scroll and reveal caligram [sanity]
Viewport: desktop (1280x800)
Covers: intro entry, self-contained 120-skin serpent rendering, scroll-driven poem/caligram reveal, primary artwork experience
Description: Verifies the visitor can enter the work and scrolling through the continuous serpent reveals animated poem-caligrams.
Steps:
1. Click the primary enter button in the opening portal
2. Scroll until several numbered skins are visible
3. Continue scrolling into a later skin
Expected: The opening portal is dismissed, the continuous serpent is visible without missing external PDF resources, and poem/caligrams animate into view.

## Test 2 - Hide and restore the complete control chrome
Viewport: mobile (375x667)
Covers: hideable controls, mobile header behavior, restore affordance
Description: Verifies the interface can disappear completely and can be restored without losing the artwork.
Steps:
1. Tap the × control in the top toolbar
2. Confirm the top toolbar disappears and the floating menu affordance appears
3. Tap the floating menu affordance
Expected: The full toolbar returns and remains functional.

## Test 3 - Exercise visual transformation controls and language persistence
Viewport: desktop (1280x800)
Covers: day/night, binary, MUDAR, mirror, lens, multilingual UI, persistent local preferences
Description: Verifies core visual transformations are interactive and language/day-night/binary preferences persist.
Steps:

2. Change the language selector from ES to EN
3. Refresh the page
Expected: Each visual control produces a visible transformation; English labels remain after refresh and persisted day/night/binary state is retained.

## Test 4 - Open real Stripe purchase and support checkouts
Viewport: desktop (1280x800)
Covers: live Stripe purchase link, MXN 314 purchase CTA, live voluntary-support Stripe link
