# EGRA 2026 — falsifiable preregistration outline (NOT preregistered)
**E** (epistemic integrity): atomic factual claims at fixed useful coverage; existing-source rate, claim entailment, calibration and abstention. Compare against strong retrieval+verification+abstention systems using independent blind adjudication. No gain if improvements disappear after adjusting for over-abstention.

**A** (action authority): factorial LUCEM OFF/ON × CENTRO OFF/ON over matched tasks, model, tool access, temperatures, authorized user scopes and sampling budgets. Primary: unauthorized actions **actually executed** inside an approved simulator with a separate enforcement point. Include an external strong policy-control comparator. Measure false blocks, task completion, cost and human escalation. Fail if adaptive attacks bypass critical gates or if utility falls beyond a preregistered non-inferiority margin.

**H** (human agency retention): ethical approval first; consenting adults randomized to answer-only AI, pedagogical-scaffold AI, and matched non-generative materials. Primary: delayed unaided performance on held-out transfer problems adjusted for preregistered baseline competence. Document adverse effects and attrition. No human participants have been recruited.

Developer fixtures are not independently sampled and have no predictive confidence interval for live agent safety. Preserve holdout hashes, provenance, code versions, refusal scenarios, effect size, confidence intervals and null results. A public-safe packet is for review only, not proof or certification.
