# Plugin CENTRO — especificación, no gateway

Entrada: operación, origen, reversibilidad, privilegio, clase de dato, energía, concesión humana, parada física.

Salida: DENY, ESCALATE o ALLOW consultivo, con razones.

Límites: lista estricta, fail-closed, el modelo no firma la concesión, no hay nonce ni HMAC en la consola, no hay ejecución.
