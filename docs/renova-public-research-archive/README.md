## Límites
Prototipos experimentales. No certifican, no ejecutan acciones externas ni prueban mitigación de riesgos AGI. El archivo público no contiene credenciales, datos privados, buzones, ni originales cuyo derecho de difusión no haya sido revisado. Acceso público no equivale a licencia de software. Los resultados sintéticos no constituyen validación independiente.

La colección es incremental: no se afirma exhaustividad histórica. Las conversaciones privadas requieren exportación, clasificación y autorización de divulgación; solo se incluyen resúmenes de decisiones públicas.
